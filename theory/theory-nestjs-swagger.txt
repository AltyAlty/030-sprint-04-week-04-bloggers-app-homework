Модуль @nestjs/swagger автоматически подхватывает структуру тела запроса и ответа, если они уже имеют соответствующие
Input DTO и Output DTO.

Декоратор "@ApiParam()" - это декоратор из модуля @nestjs/swagger, который генерирует Swagger-документацию для
параметров метода контроллера. Указывается рядом с методом контроллера и внутри описывается параметр этого метода.

Декоратор "@ApiTags()" - это декоратор из модуля @nestjs/swagger, позволяющий задать имя разделу в Swagger-документации,
который охватывает методы контроллера. Указывается рядом с контроллером и внутри указывается имя раздела, который
охватывает методы этого контроллера.

Декоратор "@ApiOperation()" - это декоратор из модуля @nestjs/swagger, который позволяет дать описание методу
контроллера. Указывается рядом с методом контроллера и внутри указывается описание этого метода.

Декораторы "@ApiCreatedResponse()", "@ApiNotFoundResponse", "@ApiOkResponse()", "@ApiNoContentResponse()",
"@ApiBadRequestResponse()", "@ApiUnauthorizedResponse()", "@ApiForbiddenResponse()", "@ApiInternalServerErrorResponse()"
и "@ApiResponse()" - это декораторы из модуля @nestjs/swagger, которые позволяют описывать ответы в
Swagger-документации. Указываются рядом с методом контроллера.

Декоратор "@ApiProperty()" - это декоратор из модуля @nestjs/swagger, который позволяет описывать свойства DTO в
Swagger-документации. Указывается рядом со свойством в DTO и внутри указывается описание этого свойства.

Декоратор "@ApiPropertyOptional()" - это декоратор из модуля @nestjs/swagger, который позволяет описывать поле для
клиента в Swagger-документации, например, указывать, что какое-то поле является необязательным для клиента. Указывается
рядом со свойством в DTO и внутри указывается значение по умолчанию для этого свойства.

Декоратор "@ApiBasicAuth()" - это декоратор из модуля @nestjs/swagger, который позволяет указать необходимость basic
авторизации для методов контроллера в Swagger-документации. Указывается рядом с контроллером или его методами.

Декоратор "@ApiBearerAuth()" - это декоратор из модуля @nestjs/swagger, который позволяет указать необходимость
предоставления JWT для методов контроллера в Swagger-документации. Указывается рядом с контроллером или его методами.
